# JavaScript Coding Practice

Practice repository for learning JavaScript fundamentals and solving coding problems.

## Repository structure

JavaScript solutions are organized by problem or lesson. Each attempt is saved as a separate file.

```text
Javascript/
  <problem-or-lesson>/
    submission-0.js
    submission-1.js
```

## Current solution

```text
Javascript/two-integer-sum/submission-0.js
```

## Run the solution

From the repository root, run:

```bash
node "Javascript/two-integer-sum/submission-0.js"
```
